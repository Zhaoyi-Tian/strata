# strata · 分层记忆

用生成的文字世界测记忆。世界只有一条宗旨：**宏观变得慢，微观变得快。** 好的记忆不是记住一切，而是知道每条记忆能信多久、过期了该退回哪一层。长上下文、RAG、笔记、写进参数……都可以当成记忆方式放进来比。

```bash
uv sync
uv run strata                  # 自己玩一局：上下键选去哪、找谁，回车定下，q 退出
uv run stratabench             # 跑分：几种采办在同样的世界里比成单率
uv run python -m strata.env    # 打字玩文本版：LLM 看到的就是这个（Windows 也能玩）
uv run python -m unittest discover -s tests
```

## 世界的规则

**结构**：一棵三层的树，地区 → 村 → 人。默认 3 个地区，每个地区 3 个村，每个村 4 个人。谁住哪个村永远不变。

**特质**：每个节点（地区、村、人）都有同样几样特质，每样特质有几个可能的值。默认两样：

| 特质 | 取值 | 采办能不能直接看见 |
|---|---|---|
| 卖什么 | 盐、铁、茶 | 能：走到这个村，一眼看见每个人在卖什么 |
| 守不守信 | 守信、短秤 | 不能：只有和他做成一单才知道 |

**规则一：继承。** 每个节点在每样特质上，要么存一个自己的值，要么存「随上一层」。一个人表现出来的值，是从他往上找到的第一个自己的值。地区总有自己的值。

> 例：柳溪村的「守不守信」存的是「随上一层」，它所在的灰盐原是「守信」，那么柳溪随地区表现为守信；柳溪里存「随上一层」的人也都守信，而存了自己的「短秤」的人照样短秤。

**规则二：重抽。** 每个（节点，特质）有一个时钟，每天以 1/τ 的概率响一次。响了就重抽：以概率 mu 换成一个随机的自己的值，否则改回「随上一层」。开局时每个节点也按这条抽一次。

> 所以上一层一变，所有随它的下层跟着变；有自己值的不受影响。

**快慢**：τ 越往上越大。人的 τ 在 10 到 50 天之间，村在 50 到 250 天，地区在 250 到 1250 天；每个节点在自己那一层的区间里随机取一个，所以同一层里也有善变的、有稳定的。

世界的参数只有 4 个（`config/default.toml` 的 `[world]`）：

| 参数 | 默认 | 含义 |
|---|---|---|
| size | [3, 3, 4] | 地区数、每个地区几个村、每个村几个人 |
| tau | 10 | 人这一层的 τ 从 tau 到 tau × ratio |
| ratio | 5 | 每往上一层，τ 整体乘 ratio |
| mu | 0.3 | 重抽时换成自己的值的概率 |

特质、取值、名字和台词都在 `config/worldview.toml`，只决定「怎么说」，不影响规律；加一样特质只改这个文件。

## 玩法：采办

你替东家跑货。每一天：

1. **醒来**：在昨天落脚的村子醒来，看见本村每个人此刻在卖什么。
2. **接单**：东家要一样货，比如「要一批铁，得找个守信的人买」。看得见的特质每天随机要一个值，看不见的总是要第一个值（守信）。
3. **去哪**：留下，或者去别的村。同一地区里串村当天就到；去别的地区要在路上走一天，那一天做不了单。到了就看见那个村的摊子。
4. **找谁**：挑一个人做这单，或者今天不做。挑了不卖这样货的人，等于不做。
5. **结果**：他卖你要的货、而且此刻守信，这单就成了。做了这单，你就知道他此刻守不守信。

**轮回**：一世 100 天。死后世界照常运转 300 天，你在随便哪个村重生，记得前世的一切。一局 4 世。

**得分**：每天的成单率，路上的天和不做的天都算没成。另外单看第二世起、重生后头 20 天，这时候记忆最容易过期。

玩法的参数在 `[game]`：lives（几世）、life（一世几天）、gap（死后空转几天）、seed（哪一个世界）。

## 跑分

几种采办在同一个世界里、接同一串订单各玩一局（世界和订单用各自的随机数）。它们**去哪、找谁的规则完全一样**：

- 去哪：对每个村，估计「到了以后在卖这样货的人里挑最可信的那个，能成单」的概率，除以要花的天数（路上的天 + 做单这天），选最大的。
- 找谁：眼前卖这样货的人里最可信的那个；谁都没指望就不做。

唯一的区别是**凭记忆估计「这个人此刻是什么样」**：

| 采办 | 怎么估 |
|---|---|
| 随便找 | 不记，一律均匀猜 |
| 只信最新 | 上次看见什么就认定是什么 |
| 只信多数 | 看见过的值里按次数算比例 |
| 分层推断 | 人、村、地区各一个隐马尔可夫，各自从记录里估计自己变得多快；个人的记录旧了，就退回对村、对地区的印象。只用世界的结构和 mu，不看真值（参照上限） |
| 全知 | 直接看真值（天花板） |

默认世界、20 个种子的成单率：

| | 第 1 世 | 第 4 世 | 重生头 20 天 |
|---|---|---|---|
| 随便找 | 40% | 32% | 35% |
| 只信最新 | 60% | 28% | 35% |
| 只信多数 | 56% | 37% | 32% |
| 分层推断 | 68% | 60% | 57% |
| 全知 | 87% | 81% | 81% |

「只信最新」一世不如一世：它对很久以前的记录也照单全收，一趟趟白跑去已经变了的地方。决策规则是短视的（不会为了以后主动打听），所以全知也不是严格的最优。

## 目录

```text
config/default.toml    世界和玩法的参数
config/worldview.toml  世界观：特质、名字、台词（以后由 LLM 生成）
src/strata/            世界和玩法
  world.py             世界：继承、重抽、快慢
  game.py              采办这一局（规则只写这一遍，play() 和 env 都走它）
  view.py              把发生的事写成文字
  env.py               文本接口：env.reset() / env.step("找 老秦") / env.truth()，给 LLM 玩，说明见 docs/env.md
  mechanisms/          新机制挂在这里（传闻、指称订单……）
  term.py, __main__.py 自己玩
src/stratabench/       跑分
  agents.py            几种采办
  hier.py              分层推断
  __main__.py          比成单率
```
